# Open-HeadOn

An open-source modern revival of **HEAD-ON**, the classic 2-player 2D gravity shooter created in 1999–2001 by **Bjørn Bæverfjord** and **Øyvind Mørk** ([Headstrong Software](http://sciencezero.org/headon)).

---

## 🎯 Mission

The goal of this project is to faithfully preserve and modernize **HEAD-ON** for contemporary platforms (macOS, Windows, Linux, and Web) using **Godot 4**.

- **100% Gameplay Fidelity:** Preserve the exact original physics (gravity, inertia, rotation angles, bounce restitution, docking).
- **Faithful Aesthetics:** Pixel-perfect 8-bit palette graphics and original sound effects.
- **Modern Hardware Support:** Cross-platform gamepad support, modern aspect ratios, fullscreen scaling, and local split-screen / multi-monitor play.
- **Respect & Attribution:** Full original credits remain with Headstrong Software.

---

## 🕹️ About the Original Game

* **Title:** HEAD-ON
* **Developers:** Bjørn Bæverfjord & Øyvind Mørk (Headstrong Software)
* **Release:** 1999–2003 (Retail 1.1a)
* **Genre:** 2D Gravity Shooter (1 or 2 players)
* **Modes:** 
  - **WAR!**: 2-player aerial dogfights with dynamic catch-up balancing.
  - **GET!**: Race to capture stars within a 99-second countdown.

---

## 🛠️ Tech Stack

* **Engine:** [Godot 4](https://godotengine.org/)
* **Languages:** GDScript / C#
* **Target Platforms:** macOS (Apple Silicon / Intel), Windows, Linux, Web (WASM)
